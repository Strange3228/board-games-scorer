# 🎲 Board Games Scorer

A mobile-first app built with **Ionic + Angular** for tracking board game sessions, scores, and player stats. Designed to be lightweight, fast, and easy to use — perfect for game nights!

---

## 🚀 Features

- 👥 Manage players with names, colors, or avatars
- 🏆 Create and reuse game templates
- 📊 View player performance and game history
- 🌓 Dark and light theme support
- 📱 Native-style tab navigation

## 🛠️ Tech Stack

- Framework: Ionic + Angular
- Languages: TypeScript, SCSS, HTML
- UI: Ionic Core components + custom reusable components
- Storage: Local (via @ionic/storage)

Built with ❤️ by a board game enthusiast.
